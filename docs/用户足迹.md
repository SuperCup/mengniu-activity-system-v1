# 用户足迹

## 2026-10-21 页面是否从 JS 改成 HTML

**问：** 当前项目页面都是 js 格式的，有没有必要换成 html 的。

**结论：** 没有必要。`index.html` / `login.html` 已是外壳；业务页用 `js/pages/*.js` 的模板函数返回 HTML 字符串，启动时挂到 `#viewRoot`，靠 `.view.on` 切换。这是为 `file://` 双击打开准备的：浏览器会拦截 `fetch` 片段和 ES Module。改成独立 HTML 会丢掉跨模块的 `getElementById` 联动，或退回原来的单文件。只有以后上本地服务器或构建工具时，才值得改成 HTML 片段或组件。

## 2026-10-21 预览主页面

用本机 Chrome 打开 `hq-console/index.html?nologin=1`。默认进入「计划与批次」（`app.js` 里 `go(MT.fromHash('v-plan'))`）。截图：`docs/preview-home.png`。直接双击 `index.html` 会先到钉钉登录页。

## 2026-10-21 为什么加载不出来

页面脚本和样式在 `file://` 下是正常的。Chrome 开在左侧副屏，主屏几乎看不到窗口，所以像没加载。已把该窗口挪到主屏。Cursor 内置浏览器不能开 `file://`，也不通本机临时端口。

## 2026-10-21 Cursor 内置浏览器不能预览

内置浏览器禁止 `file://`。先前的 `python -m http.server` 接受连接后空响应，页面显示 Connection Failed。已改用本机静态服务 `http://127.0.0.1:8787/index.html?nologin=1`，内置浏览器可以打开，默认仍是「计划与批次」。
