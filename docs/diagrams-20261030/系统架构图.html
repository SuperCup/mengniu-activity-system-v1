外部协作

会员触达、制券与微信支付能力
既有会员小程序开放 API：鉴权、发券、批次查询；消费者领券页由其承接
制券服务商在微信商户平台建券；回传批次号、商户号与账单
微信支付能力公共发券 / 券批次、卡包展示、核销数据；平台不替代商户平台
接口约定项目编号 / 计划 ID / 批次号按文本传输；BPM 按人回写结果与意见；字段校验以平台为准。

后台任务与数据处理

BPM / 预算状态同步 · 批次与账单入库 · 对账与异常检查 · 邮件通知与运行维护 · 看板指标汇总

关键集成

登录 · 钉钉审批 · BPM预算 · TPM / MEM投放 · 会员小程序制券 · 服务商券能力 · 微信支付
架构边界：平台只提交审批单并接收 BPM 的按人结果，不建设审批引擎；不代替微信商户平台建券；服务商无独立账号；批次配置在推送后锁定。门店编码来自客户系统，当前不限定格式。
