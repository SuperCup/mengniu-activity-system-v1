九、字段级规则与校验

本章是开发、测试与验收共用的字段口径。未列出的字段视为无额外约束。所有日期统一 YYYY-MM-DD，所有金额单位为元、保留两位小数，所有编码类字段按文本处理。

9.1 项目创建字段

分区字段必填类型 / 长度校验规则来源
基本信息项目名称是文本 ≤50 字同名校验提示不阻断手工
基本信息项目目标否文本 ≤100 字—手工
基本信息投放平台是枚举一期固定「微信支付」系统
基本信息活动周期（起 / 止）是日期起始不晚于结束；批次可用时间须落在其内手工
基本信息活动负责人是文本 ≤20 字—手工
基本信息联系方式是文本 11 位手机号格式校验手工
预算与费用PO 单号是文本必须存在于 PO 库且已审批手工
预算与费用核销预算是金额由 PO 带出，只读PO 库
预算与费用费用科目是文本由 PO 带出，只读PO 库
预算与费用承担主体是文本由 PO 带出，只读PO 库

9.2 批次计划明细字段

活动零售商明细（7 列）

字段必填规则
零售商名称是文本
门店 ID否留空自动生成，全库唯一
门店名称是文本
省份是文本 / 字典
城市是文本 / 字典
微信商户号否填写时须为 8~12 位数字；留空时提示「推送服务商后由服务商提报时补充」
经度 / 纬度否成对填写；经度 -180~180，纬度 -90~90

活动商品明细（4 列）

字段必填规则
69 码条件必填与店内码至少填一个；8~14 位数字
商品名称是文本
店内码条件必填与 69 码至少填一个
店内码所属零售商条件必填填了店内码时至少一个；一行只对应一个零售商

判重键：零售商明细按「门店名称 + 商户号」，商品明细按「69 码/店内码 + 零售商」。重复行在提交前拦截并列出。

9.3 补充批次信息字段（对齐微信支付后台）

字段必填规则违规提示
券名称是≤9 个汉字（超出仅提示，不阻断保存）提示「微信侧通常限制 9 个字，超出可能创建失败」
机制类型是满减 / 减至—
券面额（减至时显示「减至价」）是大于 0，最多两位小数满减：金额须大于 0 且小于门槛；减至：减至价须大于 0 且低于门槛
使用门槛满减必填 / 减至可空≥0满减门槛须大于 0
可用开始日是日期早于项目周期开始则拦截
可用结束日是日期晚于项目周期结束、或早于开始日则拦截
可用跨度—≤90 天超出仅提示，不阻断
发放总上限是整数 ≥1非整数或小于 1 拦截
单人可领（张）是整数 ≥1，且 ≤ 发放总上限超出上限拦截
使用须知是文本 ≤100 字空值拦截
批次号否6~20 位数字，全平台唯一重复或格式不符拦截；由服务商回传写入
计划预算系统计算面额 × 发放总上限只读，参与项目预算占用

9.5 导入通用规则

  1. 模板列名固定，不允许增删列；表头匹配失败时提示「模板不正确」并给出模板下载入口。
  2. 无表头文件不得丢行：整行匹配列名才判定为表头；单行文件同样可导入。
  3. 行级校验逐行返回结果，异常行给出「行号 + 字段 + 原因」，不因单行失败中断整批。
  4. 导入结果页展示：总行数、成功行数、失败行数、失败明细下载。
  5. 同一文件重复导入不产生重复数据（按判重键幂等）。

9.6 校验提示要求

  1. 表单校验错误提示定位到具体字段并说明原因，禁止只提示「参数错误」。
  2. 提交类操作一次性列出全部缺失项，不只报第一个。
  3. 拦截类提示必须说明「为什么不行 + 怎么改」，例如「第 2 行满减金额 15 元不得大于等于门槛 10 元」。
  4. 危险操作（终止、删除、覆盖导入）二次确认，确认文案写明后果。
